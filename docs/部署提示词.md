# 校园网 IPv6 免流 · 全自动部署提示词

> 本提示词供**下一个智能体（代理 / Agent）**使用，目标是在具备外部条件（Cloudflare 账号、校园网 IPv6）时，尽可能**全自动**复现整条免流链路。请逐段执行，关键校验必须通过后再继续。
>
> 本版本已**脱敏**：所有个人标识（UUID、pages.dev 域名、优选节点、订阅链接、本机路径）一律用 `<占位符>` 表示，值由你在部署时填入自己的。

## 0. 任务目标

搭建一条「校园网 IPv6 免流通道」：本机走校园网 IPv6 直连 Cloudflare 优选节点 → Cloudflare Pages(edgetunnel Worker, SNI=你的 pages.dev) 代抓 IPv4 外网 → 返回仍走 IPv6，从而免费访问外文期刊 / Google / GitHub / YouTube，速度由优选节点保证（实测约 1.2 MB/s）。

交付物：
1. 一组可用的 VLESS 节点订阅（明文 + base64）
2. 一份 Clash Verge Rev / mihomo 可直接导入的 YAML
3. （可选）在线订阅源链接
4. 用户可读的部署指南

## 1. 核心常量（全程统一，替换为你自己的）

| 常量 | 你的值 |
|------|--------|
| Cloudflare Pages 域名 | `<你的pages.dev域名>`（如 `xxxx.pages.dev`） |
| VLESS UUID | `<你的UUID>`（12-18位随机） |
| 端口 | `443` |
| WS Path | `/?ed=2560`（URL 编码 `%2F%3Fed%3D2560`） |
| 传输 | `vless + ws + tls`，SNI/Host = 你的 pages.dev 域名 |
| 伪装 | `fp=chrome&alpn=h2,http/1.1` |
| Worker 文件 | `edgetunnel-worker.js`（开源项目 edgetunnel，clone 上游或从本仓库取） |
| 计费关系 | 校园网只统计 IPv4 下行 → 本机→CF 段必须走 IPv6 |

## 2. 准备工作（Agent 需确认）

- [ ] 处于**校园网（能取到 IPv6 地址）**环境；本机网络出网 IPv6。
- [ ] 有 Cloudflare 账号，能创建 Workers / Pages 并上传 JS（本链路用 Pages）。
- [ ] 本机已装 Clash Verge Rev（内置 mihomo）或任意支持 VLESS+WS+TLS 的核心。
- [ ] Python 3 可用（运行附带 `*.py` 脚本）。

> 不在校园网则**先让用户连上校园网**，否则 IPv6 优选结果无效。

## 3. Worker 部署（Cloudflare 侧）

1. Cloudflare 控制台 → Workers & Pages → 创建 Page（连 GitHub 或直接上传），项目名建议英文（如 `xxx`），生产域名 `<你的pages.dev>`。
2. 将 `edgetunnel-worker.js` 粘贴为 Worker（或作为 Pages 的 `_worker.js`）。
3. **配置环境变量**：`UUID` = 你的 UUID，`PROXYIP` 置空。
4. 确认 `pages.dev` 生产域名已生效，能返回页面。

> ⚠️ 关键点：edgetunnel worker.js 里 `if(env.KV...)` 是分水岭——**不配 KV** 才进伪装页；VLESS WS 隧道**不依赖 KV**，所以纯 VLESS 可用，无需额外建 KV。

验证：
```bash
curl -s -o /dev/null -w "%{http_code}" https://<你的pages.dev>/
# 期望 200（伪装页）
```

## 4. 节点优选（校园网 IPv6 下执行）

```bash
python tools/cf_ipv6_selector.py -d
```
脚本扫描出一批 Cloudflare 原生 IPv6 段（`2a06:98c1:*`、`2606:4700:*` 等），对候选做 **TCP 443 + HTTPS 下载测速**，输出 TopN 及推荐地址。

取 Top 6~8 的最优 IPv6，整理成**每行一个 IPv6** 的列表供下一步使用。

> 节点时效性：CF 优选 IP 会变化，失效就重跑本脚本重选、再重新生成。

## 5. 生成订阅（VLESS URI + base64）

```bash
python3 tools/gen_vless.py --ip <你的优选IPv6>
# 或
python3 tools/gen_vless.py --ips "ip1, ip2, ..."
```
产物：`subscription.txt` + `subscription_base64.txt`。

> 脚本里的 `HOST`/`UUID` 是占位符，发布前先改成你自己的 pages.dev 域 与 UUID。

## 6. 生成 Clash YAML（自动·勿手写）

```bash
python3 tools/gen_clash_yaml.py
```
- 从 `subscription.txt` **自动解析**生成 YAML，**杜绝手抄 UUID/IP 出错**。
- 自带结构自校验，必须见 `✔ 结构校验通过`；否则修复。
- YAML 特征：`proxies` 全 VLESS+WS+TLS，`servername/Host`=你的域名，`ws-opts.path="/?ed=2560"`，`udp:true`，`ipv6:true`；`proxy-groups`=`🚀 免流`(select)+`♻️ 自动选择`(url-test)；`rules` 外文库代理、`cnki.net`/`edu.cn`/GEOIP-CN 直连、MATCH→代理。

**易错（务必遵守）**：
1. ❌ 不要手写 YAML —— 手滑写错会 404。**一律脚本生成。**
2. group 引用的节点 name 必须与 `proxies` 逐一对应，引号包裹。
3. 节点失效就从列表移除后**重跑脚本**，不手删。

## 7. （可选）在线发布订阅源

可把 `subscription_base64.txt` / YAML 发布为静态站（WorkBuddy「发布为应用」或任意静态托管），得到公开链接，客户端填 URL 即可更新。发布后逐个 `curl -I` 确认 200 且 `Content-Length` 非 0（个别平台显示 0 字节是 bug，用 `curl | wc -c` 复验）。

## 8. 客户端导入（Clash Verge Rev）

1. Clash Verge Rev → 订阅(Profiles) → 新建 → 导入本地文件（选 YAML）或填在线订阅 URL。
2. 「当前生效」切到新配置。
3. 首页**模式切「规则(rule)」**（不要全局，否则内网也被代理）。
4. 打开「系统代理」。
5. 选「🚀 免流」组，通常默认走「♻️ 自动选择」。
6. 确认出口走 IPv6：
```bash
curl -6 ifconfig.me        # 应显示校园网段 2001:da8:* 之类
curl -I https://www.nature.com
```

## 9. 验收标准

- [ ] `curl -6 ifconfig.me` 返回校园网 IPv6 段（非手机热点 IPv4）
- [ ] YAML 校验 `✔`，Clash 无红错
- [ ] 节点 alive / 延迟低
- [ ] 实测 `nature.com / sciencedirect.com / google.com` 打开成功
- [ ] 校园网内网（教务、知网 cnki）仍直连可访问

## 10. 注意事项（易错，Agent 必读）

1. **免流前提 = 校园网 IPv6**：手机热点只有 IPv4 → 非免流并计费。切热点前提醒用户。
2. **必须 rule 模式**：让内网/`edu.cn` 直连、外网代理。
3. **IP 时效**：优选 IPv6 变化就重跑优选脚本再重新生成。
4. **不手抄**：UUID/IP/path 一律脚本生成/解析。
5. **Worker 变动**：只改 worker.js 需重新部署；不建 KV 时纯 VLESS 可用。
6. **手机端客户端必须开 IPv6 开关（实测根因）**：手机用 clashbox(鸿蒙端)时，不开「IPv6」总开关 → 纯 IPv6 节点**全部 timeout**。开了即通；同时建议开「允许 IPv6 入站」，否则部分 IPv6 境外请求绕开代理直连会打不开。
7. **判断代理生效要测非 CN 站**：rules 有 `GEOIP,CN,DIRECT`，能打开百度**不算隧道通**，必须测 `google.com`/`nature.com`。
8. **测试站陷阱**：`4.ipw.cn`/`6.ipw.cn` 在某校园网 DNS 下可能无解析记录（打不开不代表网络有问题），改用 `https://ipv6.baidu.com`（实测 200）；校园网 IPv6 到 CF 是"分段可达"，别用 `1.1.1.1` 判断 CF 连通性；测节点走 Clash `mixed-port` 代理，不要裸连 IP 发 HTTPS（裸 IP 无 SNI 会被 CF 拒 TLS，报证书错误属正常）。
